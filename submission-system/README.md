# 미래산업융합학회 논문 투고 시스템

Future Industry Convergence Society - Paper Submission System

## 상태

🚧 **개발 예정** 🚧

이 디렉토리는 논문 투고 및 관리 시스템을 위해 예약되었습니다.

## 계획된 기능

- 회원 인증 및 관리
- 논문 투고
- 심사 프로세스 관리
- 결제 시스템
- 문서 관리
- 관리자 대시보드

## 기술 스택 (예정)

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Database**: PostgreSQL
- **Authentication**: JWT
- **Payment**: 토스페이먼츠/아임포트
- **File Storage**: AWS S3 또는 MinIO
